Experimental Details

In this section, we delve into the experimental details of the proposed LLaMAVID framework. Generally, we adopt a similar training strategy with that in [7],
except that we freeze the proposed text decoder during pretraining and subsequently optimize it during the finetuning phase. As outlined in Table 10, we
employ customized training settings for the distinct stages illustrated in Figure 3
of the main paper. Specifically, during the modality alignment phase (stage 1),
we keep the text decoder fixed and limit the maximum token length to 2K. Moving on to instruction tuning (stage 2), we unfreeze and optimize the text decoder,
accommodating a larger maximum token length of 2K to facilitate video tuning.
If stage 3 is adopted for long video tuning, we once again freeze the text decoder
to conserve memory resources while increasing the maximum token length to a
substantial 64K, catering to the demands of hour-long movie content. Detailed
training settings are further explicated in Table 10.
For results on Something-Something-v2 (SSv2) dataset, we evaluate the temporal understanding ability of the model in the main paper. Because the SSv2 is
an action recognition dataset with over 170 categories, we conduct the zero-shot
evaluation and match the open-ended description of LLaMA-VID with the annotated caption using GPT3.5, same to that in MSRVTT-QA benchmark. We
do not find such an evaluation with open-ended results in previous work, so we
set up a baseline with Video-ChatGPT using the same manner.

Instruction Tuning Details

Context Extension. To support hour-long video understanding, we conduct
context extension of the language model in LLaMA-VID to accommodate inputs
of up to 64K tokens. In line with prior research on long context LLMs [2, 3], we
employ position interpolation techniques [2] to scale the rotary position encoding [11] from 4K to 64K, thereby enabling the processing of extended sequences.
Subsequent to this adaptation, we perform supervised fine-tuning using LongVideoQA, a dataset specifically designed for long-duration video instructionfollowing tasks.
