Experimental Setting

1.1

Descriptions of datasets

For the in-distribution (ID) dataset CIFAR-100, we use three common benchmarks as OOD datasets following [12] including CIFAR-10, ImageNet_R [7] and
LSUN [15]. LSUN is a scene recognition dataset. ImageNet_R contains various
artistic renditions of object classes from the original ImageNet dataset [3].
For ID dataset ImageNet, we use four common benchmarks as OOD datasets
following the work [9] including iNaturalist [10], SUN [13], Places365 [16], and
Texture [2]. iNaturalist is a real-world dataset containing 8,142 fine-grained
species. SUN is a scene recognition dataset containing 397 categories and 108,754
images. Places365 consists of images for scene recognition containing 365 scene
categories. Texture is a dataset consisting of images of described Textures. These
OOD datasets provide a comprehensive benchmark for our algorithm and span
a diverse range of domains.
We also conduct experiments with several versions of the ImageNet test set
similar to ImageNet-1K but with diverse domain shifts, including ImageNetA [4], ImageNet-R [5], ImageNet-v2 [8], and ImageNet-O [6].
1.2

Training details

For DPM-T, the learnable modules are trained on a system equipped with
4×NVIDIA RTX4090 (24G) and 2×Intel Xeon Platinum 8249C. All experiments involving our proposed algorithms are independently repeated three times,
and the reported results are averaged from these three experiments. Specifically
speaking, we experiment with several model architectures including ViT-B-16
and ViT-B-32. For CIFAR-100, all the learnable modules are trained for 30
epochs using an SGD optimizer with a momentum of 0.9 and the cosine learning
rate scheduler, which gradually decays the learning rate from 0.005 to 0. The
weight decay is 5 × 10−4 , and the batch size is 512. For ImageNet, we train the
learnable modules from scratch for 20 epochs using the same SGD and learning
rate scheduler as on CIFAR. The weight decay is 5 × 10−4 , and the batch size is
256.
