Definition Details

The connection type between two LEGO bricks can be divided into four
categories including x-axis offset, y-axis offset, z-axis offset, and relative rotation.
We define the z-axis offset separately as direction type dirn and the remaining
as tree connection type tn . Exiting works [1, 4] represent the connection type
between any two LEGO bricks as an action. However, this leads to an excessively
large search space when constructing a 3D object with tens of bricks. To reduce
the search space, we redefine an action as the connection between the current
brick with all its neighbors instead of any two bricks. We denote the action type
as an .
Direction Type. The direction type is denoted by dirn ∈ {0, 1}, where 0 represents that the brick bn is on top of its parent brick, and 1 indicates the opposite
direction, i.e. at the bottom of its parent brick. For example, the direction type
of the blue brick in Fig. S1 is dirblue = 0 when taking the red brick as the parent
brick.
Tree Connection Type. The tree connection type tn ∈ {0, 1, ..., T } encodes
the information on the x-axis offset, y-axis offset, and relative rotation. We follow
the definition in [1, 4] and show all possible 16 tree connection types between
two 2 × 4 LEGO bricks in Fig. S1.
