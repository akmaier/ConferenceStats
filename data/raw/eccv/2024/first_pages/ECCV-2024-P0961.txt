B. Additional experimental results.
B.1 Additional implementation details.
For the one-stage training, batch size is set to 2, and the large model and small
model are optimized jointly using the AdamW optimizer. The learning rate of
the large model is set to 0.0005. For three different small models, i.e., Mask RCNN [3], U2Net [5], and SINet [2], the learning rate is set to 0.0005, 0.001, and
0.0005, respectively. Cosine annealing decay is applied, and the epoch is set to
40.
