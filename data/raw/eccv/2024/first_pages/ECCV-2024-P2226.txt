Theorem 1. Let fˆ denote a 1-NN classifier trained on xl , f (xl ) l=1 , for a
deterministic labeling function f . Let k be a nonnegative function such that for
any x, if ∥x1 − x∥ ≤ ∥x2 − x∥, then k(x, x1 ) ≥ k(x, x2 ). Then
  \Pr _{\vecx }\left ( f(\vecx ) \neq \hat {f}(\vecx ) \right ) \le \left ( 1 - \E _{\vecx }\left [ \max _{\vecx ' \in \mathcal {L}} k(\vecx , \vecx ') \right ] \right ) + \E _{\vecx }\left [ \max _{\vecx ' : f(\vecx ) \ne f(\vecx ')} k(\vecx , \vecx ') \right ] \label {eq:ourbound} . (3)
Proof. We begin with
  &\Pr _{\vecx }(f(\vecx ) \ne \hat f(\vecx )) = \E \left [ \mathbbm {1}[f(\vecx ) \neq \hat {f}(\vecx ) ] \right ] \\ &= \E \left [ \mathbbm {1}[f(\vecx ) \neq \hat {f}(\vecx ) ] (1 - \max _{\vecx ' \in \mathcal {L}} k(\vecx , \vecx ') ) \right ] + \E \left [ \mathbbm {1}[f(\vecx ) \neq \hat {f}(\vecx ) ] \cdot \max _{\vecx ' \in \mathcal {L}} k(\vecx , \vecx ') \right ] \\ &\leq 1 - \E \left [ \max _{\vecx ' \in \mathcal {L}} k(\vecx , \vecx ') \right ] + \E \left [ \mathbbm {1}[f(\vecx ) \neq \hat {f}(\vecx ) ] \cdot \max _{\vecx ' \in \mathcal {L}} k(\vecx , \vecx ') \right ] 

using in the last line that 1[f (x) ̸= fˆ(x)] ≤ 1. Now consider the value
  g(\vecx ) = \mathbbm {1}[f(\vecx ) \neq \hat {f}(\vecx ) ] \cdot \max _{\vecx ' \in \mathcal {L}} k(\vecx , \vecx ') .
Recall that fˆ(x) is f (x′ ), where x′ = argminx̃∈L ∥x − x̃∥. Thus, for any given x,
there are two cases:
1. f (x) = fˆ(x). In this case, g(x) = 0, and is hence upper-bounded by
  \max _{\vecx ' : f(\vecx ) \ne f(\vecx ')} k(\vecx , \vecx ') \ge 0 .
2. f (x) ̸= fˆ(x). Let x̃ be the nearest point in L to x. We know that f (x) ̸= f (x̃),
and hence
  k(\vecx , \tvecx ) \le \max _{\vecx ' : f(\vecx ) \ne f(\vecx ')} k(\vecx , \vecx ') .
We also know that because x̃ is the closest point in L to x,
  k(\vecx , \tvecx ) = \max _{\vecx ' \in \mathcal L} k(\vecx , \vecx ') .
Thus
  \max _{\vecx ' \in \mathcal L} k(\vecx , \vecx ') \le \max _{\vecx ' : f(\vecx ) \ne f(\vecx ')} k(\vecx , \vecx ') ,
as desired.
Thus E g(x) ≤ E maxx′ :f (x)̸=f (x′ ) k(x, x′ ), giving the desired result.
