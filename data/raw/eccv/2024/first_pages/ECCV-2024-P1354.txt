Model Complexity. The measurement of complexity for a function class is
commonly evaluated by its Gaussian complexity, as shown in popular work [6,21,
24]. The definition of empirical and population Gaussian Complexity for a vectorvalued function class \protect \mathcal  {Q}, comprising functions \protect \mathbf  {q}(\cdot ): \mathbb {R}^d \to \mathbb {R}^r , and associated
with a data matrix \protect \mathbf  {X} containing N datapoints, is presented as follows:
  \hat {\mathfrak {G}}_{{\mathbf {X}}}(\mathcal {Q}) = \mathbb {E}_{\mathbf {g}}\left [\sup _{\mathbf {q} \in \mathcal {Q}} \frac {1}{N} \sum _{i=1}^N g_{i} \mathbf {q}(\mathbf {x}_{i})\right ],

where \protect \mathbf  {g} = \{g_{i}\}_{i\in [N]} is a matrix of Gaussian random variables, each g_{i} following an independent and identically distributed normal distribution \protect \mathcal  {N}(0, 1). The
population Gaussian complexity is estimated through the expectation
, which aggregates the empirical
complexities over the dataset \protect \mathbf  {X}.

In parallel, the Rademacher Complexities for the same function class  \mathcal {Q}  can
be defined as:
  \hat {\mathfrak {R}}_{\mathbf {X}}(\mathcal {Q}) = \mathbb {E}_{\mathbf {\epsilon }}\left [\sup _{\mathbf {q} \in \mathcal {Q}} \frac {1}{N} \sum _{i=1}^N \epsilon _{i} \mathbf {q}(\mathbf {x}_{i})\right ], 

(14)

where  \mathbf {\epsilon } = \{\epsilon _{i}\}_{i\in [N]}  is a matrix of random variables with each  \epsilon _{i}  independently

\protect \mathfrak  {R}_{N}(\mathcal {Q}), is inferred through the expectation \protect \mathbb  {E}_{{\mathbf {X}}} [\hat {\mathfrak {R}}_{{\mathbf {X}}}(\mathcal {Q})], averaging the empirical complexities across the dataset \protect \mathbf  {X}.
