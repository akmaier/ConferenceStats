Dataset Detail

In-shop Clothes retrieval dataset [3] is a large subset of DeepFashion with
large pose and scale variations. This dataset consists of a training set containing
25,882 images with 3997 classes, a gallery set containing 12,612 images with 3985
classes and a query set containing 14,218 images with 3985 classes. The goal is
to retrieve the same clothes from the gallery set given a fashion image from the
query set. We use both the training set and the gallery set for training in our
experiments.
CUB200 [6] is a fine-grained dataset containing 11,788 images with 200 classes
belong to birds. There are 5,994 images for training and 5,794 images for testing.
