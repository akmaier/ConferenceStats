1.1

Hough Transform with 3D Scoring Function

In Sec. 4.3 and Fig. 9, with RGB-D inputs, we utilize the 3D scoring function
Eq. (6). For a pixel pi on frame i, denote its backprojected 3D ray on the image
coordinate system of frame j as l̂i . The ray l̂i is determined by two 3D points:
  \hat {\mathbf {p}}_1 = \mathbf {R}_{i, j} \mathbf {K}\inv \mathbf {p}_i + \mathbf {t}_{i, j}, \quad \hat {\mathbf {p}}_2 = \mathbf {t}_{i, j}. 

(1)

The depth of 3D point p̂1 can be set to arbitrary values. We set it to 1 for convenience. 3D point p̂2 is the frame i camera origin on frame j. Correspondingly,
the backprojected 3D point p̂π is:
  \hat {\mathbf {l}}_i^\intercal \hat {\mathbf {p}}_{\pi } = 0, \; \hat {\mathbf {p}}_{\pi } = \pi ^{-1} (s_i, s_j, r_i \mid \overline {\mathbf {P}}_i, \overline {\mathbf {P}}_j, d_i). 

(2)

To be an inlier of the scoring function f 3D p¨q, we have:
  \small \| \hat {\mathbf {p}}_{\pi } - \hat {\mathbf {p}}_j\|_2 \leq \lambda ^{\text {3D}}, \; \hat {\mathbf {p}}_{j} = \pi ^{-1} (s_i, s_j, r_j \mid \overline {\mathbf {P}}_i, \overline {\mathbf {P}}_j, d_j). \label {eqn:sphere} 

(3)

viable solution is to first execute with 2D scoring function, fix the adjustments,
and then employ the 3D scoring function. We did not experiment with this strategy since we already had competitive performance. When with RGB-D inputs,
