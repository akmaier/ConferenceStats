Proof for Theorem 2

This section provides a detailed statement and proof of Theorem 2, considering
a more general framework. We start with the following definition.
Definition 1. Given Ω ⊆ Rd , we say a map g(t, x) : [0, T ] × Ω → Rm is
Lipschitz in x and piece-wise Lipschitz in t, if there exists a partition 0 = t0 <
t1 < · · · < tn = T such that g is Lipschitz continuous in both t and x on each
(ti , ti+1 ) × Ω.
Theorem 3. Assume r(x, θt ) is piece-wise Lipschitz continuous in t and Lipschitz in x, as per Definition 1. Consider any compact set K ∈ Rd and ε > 0.
Suppose A and B are controls that are piece-wise continuous over the interval
[0, T ]. Then, there exist functions Abinary and Bbinary , which are also piece-wise
continuous over [0, T ], and whose entries are binary values for each t ∈ [0, T ],

Proof (Proof of Theorem 3). Consider u = (A, B), and f (t, x, u) := r(x, θt ) +

For given A, B, take h(t, x) := r(x, θt ) + At x + Bt . Suppose all the entries of

of pairs (A, B) where A, B only takes binary values {−c, +c}.
