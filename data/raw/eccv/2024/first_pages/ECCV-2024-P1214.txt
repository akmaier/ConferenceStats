Implementation Details

SDS guidance. We implement our approach based on the threestudio framework [4], which includes implementations of MVDream [11] for 3D-aware textto-image diffusion and score distillation sampling (SDS), ProlificDreamer [12]
with Stable Diffusion [10] (text-to-image diffusion and VSD), and we implement
video SDS using VideoCrafter2 [2].
Hyperparameter values. We initialize the 4D neural representation following [5,
7] and add an offset to the density predicted by the network in the center of
the scene to promote object-centric reconstructions in the static stage. For the
deformation network, we use a 4D hash grid with 8 levels, 2 features per level,
and a base resolution of 4. We decode the dynamic hash grid features into a 3D
deformation vector with a small two layer multi-layer perceptron (MLP) with
64 hidden features. We set the learning rates to 0.01 for the static hash map,
0.001 for the deformation hash map, and 0.0001 for the deformation MLP. The
number of training iterations for the two static stages of hybrid SDS [1] as well
as the dynamic stage are set to 10000, 10000, and 10000, respectively. We set
the probability for hybrid SDS in the static stage to 0.5, following 4D-fy [1].
The intrinsic motion scale Mv is set to 0.3 for all text prompts. Increasing
Mv leads to larger jumps between each timestep and a tendency towards lowfrequency motion; smaller values of Mv lead to high motion variation between
nearby samples on the trajectory and high-frequency motion. Overall, this hyperparameter depends on the specific text prompt, and per prompt tuning could
