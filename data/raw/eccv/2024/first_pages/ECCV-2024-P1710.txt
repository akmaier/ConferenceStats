A

Related Work

Earlier works [3, 13, 23, 24, 30] in the area focus on studying simplified web and
mobile screens. With recent advances in both LLMs [1, 9, 11, 15, 16, 27, 32] and
MLLMs [6, 20, 21, 25, 26, 31, 37, 47], the approaches to many research problems
have been transformed, including UI understanding. Several works have explored
the use of MLLMs for UI tasks. Specifically, ILuvUI [17] and Spotlight [22] concentrate on single-screen UI tasks while exploring various UI tasks by fine-tuning
on GPT-generated data and delving into UI tasks such as screen summarization
and widget interaction.
MobileAgent [33] and AppAgent [40] represent a different approach, utilizing
MLLMs as agents for UI screen navigation, with MobileAgent employing external
detection modules for action generation and AppAgent leveraging overlaid UI
element IDs and screen XML files for predefined actions. CogAgent [14], built
upon CogVLM [34], shifts the focus towards using only screen images for complex
UI navigation, eliminating the need for UI-specific modules. Here are some more
examples among other works that utilize LLMs [8, 12, 18, 46] and MLLMs [2, 5,
10, 29, 35, 39, 45] in the space.
In this work, we focus on fine-grained mobile UI understanding with MLLMs.
Naturally, our work also aligns with the recent burgeoning literature focused on
empowering MLLMs for referring and grounding tasks [4, 19, 28, 38, 41, 42, 44].

B

Data Details

B.1

UI Screens

For Android screens, we use a subset of the RICO dataset [7]. Specifically, we
consider the tasks in Spotlight [22], whose data is publicly available, including
screen2words, widgetcaptions, and taperception. We aggregate unique images for
each split (train and test) among the tasks to form our own data splits. In total,
there are 26,527 train images and 3,080 test images.
