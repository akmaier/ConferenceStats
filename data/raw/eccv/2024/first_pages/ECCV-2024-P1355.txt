Implementation Details

In this section, we provide a comprehensive overview of the architecture employed in our study. This architecture is carefully designed to address the requirements of part-based point cloud completion tasks.
1.1

Part-Based Decompostion

We employ DGCNN [8] as our part segmentation network for obtaining part
labels in the real domain. The network takes 2048 points as input and computes
a feature set of size 64 for each point. To select reliable labels, we set a threshold
to filter out noisy points, removing at least 5% and up to 10%. As shown in Fig. 1,
filtering out lower confidence points effectively removes the noise observed in the
red box. The part labels obtained through this process are used to form part
input sets for further analysis.
