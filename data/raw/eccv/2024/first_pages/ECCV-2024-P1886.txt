MedRAT: Unpaired Medical Report Generation via Auxiliary Tasks
Supplementary Material

1. Implementation details
1. Feature extraction:
(a) Visual feature extraction: we use ResNet-101 pretrained on ImageNet, which yields a 7 × 7 grid of patch features.
Images are first resized, such that the smaller edge of the image is of size 256 pixels. Then, the image is cropped to
224 × 224 pixels.
(b) Textual feature extraction: we use an embedding layer (LUT).
(c) Feature dimension is set to d = 512.
(d) ER and EI contain 2 multi-head attention layers, each of 8 heads.
2. Shared memory:
(a) The number of memory vectors is set to M = 1024.
(b) The dimension of the memory vectors is d = 512.
(c) For the top-K selection, K = 32.
3. Shared encoder-decoder:
(a) ES contains 1 multi-head attention layer of 8 heads.
(b) DR contains 2 multi-head attention layers of 8 heads.
(c) For augmenting the input of DR we use a dropout of 0.9, or additive Gaussian noise with σ = 5.
4. Auxiliary tasks:
(a) The classification head is composed of two linear layers with a ReLU activation function between.
(b) For the contrastive learning, the visual augmentations on the input images are random crop, random rotation &
shear, random contrast & brightness adjustment and random blur. The textual augmentation is a random shuffle of
the report sentences. Additionally, τ = 0.07.
5. Optimization parameters:
(a) We set the loss weights to γ1 = 1, γ2 = 1 and γ3 = 30.
(b) We use Adam optimizer, with betas of (0.9, 0.98) and weight decay of 5 · 10−5 .
(c) The initial learning rate is set to 10−4 for the visual backbone (ResNet) and 5 · 10−4 for the other network
parameters. Every 50k training steps, the learning rate is reduced by a factor of 0.8.
6. Inference parameters:
(a) The reports are samples using beam search, with a beam of size 3.
7. Resources:
(a) We train the model on a single Nvidia V100 32GB GPU.
