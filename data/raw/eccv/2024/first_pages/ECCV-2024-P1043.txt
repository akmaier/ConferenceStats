Source Code

We provide the source code for training the proposed Disentangle and Localize (DEAL) concept-level explanations of VLMs. From the following Github
link: https://github.com/tangli-udel/DEAL, you can access the source code and
pretrained weights. The code is built on Pytorch 2.0.1 with CUDA 12.2. Our
experiments are deployed using one Nvidia RTX A6000 GPU. To start training:
sh DEAL/run.sh

Additional Results

2.1

Comparison with Fine-tuned Models

To better evaluate the effectiveness of the proposed constraints, we compare our
method with zero-shot and representative fine-tuning methods (i.e., full model
fine-tuning, and vision-encoder-only fine-tuning of CLIP) on the five benchmark
datasets. We use Grad-CAM [18] for ResNet-50 and [2] implementation for ViTB/32 to generate explanations w.r.t. concepts. Here we provide our results of
all datasets in Tab. 1 as the full table of Tab.2 in the main paper. As shown,
our model outperforms standard fine-tuning models in terms of explanation and
prediction performance.
