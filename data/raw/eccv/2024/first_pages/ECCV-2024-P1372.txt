Implementation Details

We employed the AdamW [8] optimizer with the default parameter settings
within the charbonnier loss [3]. We set a batch size of 4, and the learning rate is
decreased from 1 × 10−4 to 5 × 10−5 with a multi-step scheduler. We empirically
set the iteration number to 4 of the CRIFE module. We use a voxel bin size B of
16 for event representation. Additionally, we employ a random crop with a spatial
resolution of 256 × 256, ensuring the same spatial position in both the embedded
event data and video frames. We set the dynamic filter size sk to 3. We generate
3 and 1 deblurred results using 7 and 5 frames as inputs from the GoPro dataset,
respectively. From the HighREV dataset, we generate 1 deblurred result using
5 frames as input. Additionally, from the EVRB dataset, we produce 3 restored
results using 5 frames as input. For the evaluation of the HighREV dataset
(Tab. 2 in the main paper), since trained models on the HighREV dataset do
not exist for EFNet [13], UEVD [5], DSTNet [10], and ESTRNN [17], we retrain
the models ourselves to evaluate the results. For the REFID [14] model, we used
the official pretrained model to evaluate on the HighREV dataset.
