Implementation Details

1.1

Dataset Details

Below, we describe all the datasets used in the main text along with the exact
data augmentations. We use the same processing for all our experiments.
CIFAR-100 [11] contains 50K training and 10K test images from 100 classes
with size 32 × 32 × 3. We use basic data augmentations: ‘RandomCrop‘, ‘RandomHorizontalFlip‘, and ‘Mean-Std-Normalization‘.
Tiny-ImageNet [12] consists of 100K training and 10K test images from 200
classes with size 64 × 64 × 3. Note that it is a subset of the popular ImageNet1K dataset russakovsky2015imagenet. We use the same augmentations as the
CIFAR-100 dataset.
ImageNet-1K [17] contains around 1.2M training and 100K test images from
1000 classes with size 224 × 224 × 3. We use ‘RandomCrop‘, ‘RandomHorizontalFlip‘, and ‘Mean-Std-Normalization‘. In addition, we include the ‘RandAugment‘ implementation from the timm repository [20].
Fine-tunning Datasets. We directly use dataset class from PyTorch of datasets
CUB [19], Oxford-Pet [16], Food-101 [1] and Stanford Car [10] for fine-tunning
tasks. We only apply base augmentations same as CIFAR-100 dataset. Same
image sizes are applied for the fine-tunning datasets with the pre-trained dataset.
1.2

Model Details on Different Problem Settings

Supervised Learning. For supervised classification from scratch, we evaluate ResNet18 [6], ResNet34, ResNet50 and ShuffleNetV2 [14] on CIFAR-100
experiments. We evaluate ResNet18, ResNet50, ViT-t [4] and Swin-t [13] architectures on ImageNet-1K experiments. The transformer-based architectures
implementations are from the timm repository [20].
