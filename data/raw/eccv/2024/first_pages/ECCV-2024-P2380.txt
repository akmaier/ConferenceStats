A.1

GPT-4V Evaluation

Filtering objects Initially, the original image is fed into the GPT-4V model.
The provided prompt is: Task Assuming you are an object detector, please tell me
the prominent foreground objects appears in the given image. The objects should
be a part out of the coco detection dataset # Output Format Please directly
respond with the names of the objects without adding any additional content
or period. If there are multiple objects, please separate them with a comma. If
there are no objects at all, please respond with none. # Example Input: A image
Output: cat, potted plant Input: A image Output: none. This process yields a list
of detected objects.
Removal Rate We introduce images generated with negative prompts into
the GPT-4V system, using the prompt: ’tell me ’yes’ if the image contains the
{negative_prompt}, otherwise, tell me ’no’. At inference, the ’negative_prompt’
is substituted with specific items, such as ’glasses’.
Compare Rate We input three images at one time: the original image, an image
generated with negative prompts applied at all stages, and an image produced
using our method. We then query GPT-4V: which pic looks more similar to the
first one, please answer with ’the second one’ or ’the third one’. A response of
’the third one’ suggests superior performance by our method.
For more details, please refer to the autotesting.py file in the code folder.
