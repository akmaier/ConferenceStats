A1 Impact of Different Symbolic Operators
Following Section 4, here we present the study on three different operator settings, namely Operator Set 1, Operator Set 2, and Operator Set 3.
Operator Set 1 This set is used in the main paper, as shown below:
g, g 2 , g 3 , ag, m, v, sign(g), sign(m), ad, rs, ld, cd, 1, 2, identical, (·)2 ,
exp, sign, −(·), +, −, ×.
Operator Set 2 Compared to Set 1, the decay-related operators are removed.
This is because decay-related operators were introduced in the study of automated optimizer search [1], whereas few hand-designed optimizers had them. We
intend to see whether they are necessary. The operators in the set are:
g, g 2 , g 3 , ag, m, v, sign(g), sign(m), ad, rs, 1, 2, identical, (·)2 , exp,
sign, +, −, ×.
Operator Set 3 This is a relatively simple set, which only contains 11 operators.
As explained in the main paper, the operators g, m, v are the gradient, first-order
momentum, and second-order momentum, respectively. They are the most basic
and important elements in terms of determining parameter updates. Operators
(e.g., exp and +) are the basic unary and binary operators. This set is to show
whether these basic operators are sufficient or not for an effective optimizer.
g, m, v, identical, (·)2 , exp, sign, −(·), +, −, ×.
