A.1

Outlier Datasets

19

We introduce the details of the outlier datasets we used in this section. SVHN
[37] dataset is a digital collection that includes 50000 images for training and
10000 images for testing. LSUN [57] is a collection of large-scale labeled images
designed for various scene understanding. In our experiment, we resize the image
to 32×32. TinyImageNet [25] is an image classification dataset has 200 classes.
Each class has 500 training images, 50 validation images, and 50 testing images.
Textures [6] is composed of 5,640 texture images that are classified into 47
categories. Places365 [64] is a scene recognition dataset containing over 10
million images in total, including over 400 unique scene categories.
A.2

Additional Implement Details

Hyperparameters. For all baseline methods and our method, we tune the
hyperparameter according to the H-score on the Gaussian Noise corruption with
Noise outliers. The tuned hyperparameters are applied to all the domains and
outlier datasets. We list the tuned hyperparameters for each method as follows:
Ours For augmentation, we apply the same augmentation for CIFAR10-C
following [54]. For other datasets, we apply random crop and random horizontal
flip augmentation. In addition, since there are 1,000 classes in ImageNet, requiring the source model to be consistent with the current model output will result
in filtering out a large number of samples, so we removed consistency filtering
on the ImageNet experiment.
Tent For Tent [51], we set the learning rate LR = 0.001/0.0001/0.00025
for CIFAR10-C/CIFAR100-C/ImageNet-C. We referred to the official code 5 for
implementations.
CoTTA For CoTTA [54], we set the learning rate LR
=
0.001/0.001/0.0001, the restore constant p = 0.005/0.005/0.00005 and the
threshold pth = 0.95/0.9/0.05 for CIFAR10-C/CIFAR100-C/ImageNet-C. We
referred to the official code 6 for implementations.
EATA For EATA [38], we set the learning rate LR = 0.001/0.001/0.0005,
the cosine sample similarity threshold ϵ = 0.2/0.1/0.025, the entropy threshold
E0 = 0.4×ln|CS |, and the F isherα = 1 for CIFAR10-C/CIFAR100-C/ImageNetC. We referred to the official code 7 for implementations.
SAR For SAR [39], we set the learning rate LR = 0.005/0.005/0.0005, the
reset threshold Θ̃ = 0.3/0.2/0.1 and the entropy threshold E0 = 0.4 × ln|CS |
for CIFAR10-C/CIFAR100-C/ImageNet-C. We referred to the official code 8 for
implementations.
