Softmax Temperature and Tuning the FPR

In this section we demonstrate that MaxLogit can always be outperformed
by MSP/MCM in terms of the FPR by choosing the right temperature. Let
s(1) (x), . . . , s(K) (x) be the logits for a sample x in descending sort order. The
MaxLogit decision rule is given by
  \begin {cases} 1 & \text {if } s^{(1)}(\vx ) \ge \lambda ^0 \\ 0 & \text {if } s^{(1)}(\vx ) < \lambda ^0, \end {cases}
(1)
where λ0 is a score threshold to achieve a certain TPR (e.g. 95%). Let FPR0 (λ0 )
be the FPR of MaxLogit for a given choice of λ0 .
It is beneficial to state the MSP/MCM decision rule using log-probabilities,
  \begin {cases} 1 & \text {if } s^{(1)}(\vx )/\tau - \LSE _i (s^{(i)}/\tau ) \ge \lambda \\ 0 & \text {if } s^{(1)}(\vx )/\tau - \LSE _i (s^{(i)}/\tau ) < \lambda , \end {cases}
(2)
where the log-sum-exp is given by
  \LSE _i(a_i) := \log \sum \nolimits _{i=1}^K \exp (a_i).

(3)

Here i denotes the class index, ai is the corresponding logit, and K is the total
number of classes per dataset. Further, let Qx be the distribution of outliers. As
in the main text we assume that s(i) (x) are bounded from below, more precisely
we assume that s(i) (x) ≥ L Qx -a.e. (i.e. Qx (mini s(i) (x) ≥ L) = 1). Hence,
w.l.o.g. we can assume that λ0 > L. Now
  \mathrm {FPR}(\lambda ,\tau ) &= Q_\vx \left ( \tfrac {1}{\tau } s^{(1)}(\vx ) - \LSE _i (\tfrac {1}{\tau } s^{(i)}) \ge \lambda \right ) \nonumber \\ &= Q_\vx \left ( s^{(1)}(\vx ) \ge \tau \lambda + \tau \LSE _i (\tfrac {1}{\tau } s^{(i)})) \right ) \nonumber \\ &\le Q_\vx \left ( s^{(1)}(\vx ) \ge \tau \lambda + \tau \LSE _i (\tfrac {1}{\tau } L)) \right ) \nonumber \\ &= Q_\vx \left ( s^{(1)}(\vx ) \ge \tau \lambda + \tau \log (K \exp (L/\tau )) \right ) \nonumber \\ &= Q_\vx \left ( s^{(1)}(\vx ) \ge \tau (\lambda + \log K) + L \right ).

(4)
