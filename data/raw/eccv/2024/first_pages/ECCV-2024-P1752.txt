We describe the Farthest Point Sampling (FPS) algorithm, which samples n =
N/stride (stride = downsampling rate) output points from given N input points
in a way that maximizes the distances of points in order to preserve the boundary
of the 3D point cloud. We explain this process in detail with Algorithm 1.
Given the input point set P of N input points and the index of the seed point
seed, the final goal of this algorithm is to generate the indices of n sampled points
(i.e., fps_idx). The initial length of fps_idx is 1 since FPS starts sampling with
the seed point (Line 2). As the process continues, it will append (n − 1) more
sampled points to the list. Also, we define min_dist of length N initialized with
inf values (Line 3). The usage of min_dist[i] is to keep track of the minimum
distance between an input point P [i] and a group of sampled output points so
far.
