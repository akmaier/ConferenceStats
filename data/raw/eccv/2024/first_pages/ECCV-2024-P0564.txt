Implementation Details

2.1

Pseudo Code

We list the pseudo code of our GS-LRM in Algorithm 1 1 . The code implements
the method that we discussed in the main method section, and also the Gaussian
parametrization detailed later in Sec. 2.4.

2.2

Additional Model Details

We do not use bias term in the whole model, which includes both Linear and
LayerNorm layers. We initialize the model weights with a normal distribution of
zero-mean and 0.02-stddev.
