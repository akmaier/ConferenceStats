Implement Details

A.1

Network Architecture

For the RGB-D image encoder, we use two parallel ResNet-18 as the backbones,
and aggregate the RGB and depth features after each residual block weighted by
a soft-based spatial attention mechanism, similar to [1, 5]. Assuming the input
feature maps Frgb ∈ RC×H×W and Fd ∈ RC×H×W , where C, H, and W denote
the channel number, height, and width of feature maps, respectively, we first
concatenate the input feature maps along the channel dimension. Then, we apply
a 1×1 convolution with an output channel of 2, followed by a softmax function
to generate the spatial attention maps Argb ∈ R1×H×W and Ad ∈ R1×H×W :
  A_{rgb}, A_{d} =Softmax(\phi (F_{rgb}\Vert F_{d})), 

(1)

where ∥ represents the concatenation along the channel dimension, ϕ represents
the 1×1 convolution layer. Finally, we aggregate the RGB-D features by weighted
summation:
  F_{fused}=F_{rgb}\odot A_{rgb} + F_d\odot A_d, 

(2)

where ⊙ represents the element-wise multiplication.
For coarse-to-fine SDF learning, during inference, we map the coarse-level
SDF only for depth cloud with dimension RNpcl ×3 . Compared to fine-level SDF
learning with query points ∈ RNS ×3 as input, our two-stage SDF strategy introduces almost no additional inference time, since Npcl ≪ NS , where Npcl and NS
indicate the number of depth points and sampled query points.
