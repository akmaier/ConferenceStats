Implementation Details

The deep neural network architectures for the encoder, the 3D decoder and the
2D decoder are illustrated in Fig. 1. We set the output resolution of the image
generation network to 64 × 64 pixels. For each category, we train the network
for 10 epochs using Adam with a learning rate of 3e−2 , which takes 8 hours on
a GTX 1080Ti GPU. At inference time, we also use Adam and optimize for 50
iterations which we empirically found sufficient for our algorithm to converge.
We initialize with 32 random seeds.

Fig. 1: Network Architectures. The parameters for the convolution and transposed convolution layers are specified in the following order: number of filters,
filter size, stride and padding size.
