More Details on Generating Temporal GoPro Dataset

Our Temporal GoPro dataset was generated as follows:

Input: K consecutive sharp images I1 , ..., In
for k = 1 to n do

end
B̂ ← Mean(Iˆ1 , ..., Iˆn )
B ← B̂ 1/γ

Using a set of consecutive sharp images I1 , ..., In , a blurred image B is synthesized through the above algorithm where n denotes the temporal level, TLn. The
original GoPro dataste [31] approximated a non-linear CRF (camera response
function) as a gamma curve with γ = 2.2. Our Temporal GoPro dataset was
simply generated by using a linear CRF with γ = 1.
