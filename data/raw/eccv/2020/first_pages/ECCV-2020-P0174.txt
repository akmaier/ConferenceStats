Dependency on λ and µ
Our training has 3 stages (Sec. 3.4): the model was firstly learned with the
reconstruction loss Lrec then added cycle-consistent flow loss Lc and finally
trained with all the losses (Equation 1). In Table 1, we provide an analysis
on the weighting parameters λ and µ on sparse correspondences evaluation on
MegaDepth [37] and report the accuracy at 3 pixels. We can see the stage 2 is
not very sensitive with respect to µ (Table 1a), while the stage 3 with adding
the mask loss is slightly more sensitive (Table 1b). Note that we then use the
same parameters for fine-tuning on the different datasets.
