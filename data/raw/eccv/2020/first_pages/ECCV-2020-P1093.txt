Network Architectures
For fair comparison, we follow the network in DANN [1] and simply build the
autoencoder network by fully connected layers. Here we provide all the network
architectures in the extensive experiments. For digit adaptation tasks with 32×32
images, we draw the specifications of CNN and fully connected layers in Table
1. For object recognition tasks on Office-Home and Image-CLEF, we draw the
network architectures in Table 2. We could see that we only involve several fully
connected layers compared with domain adversarial training [1], which are still
computational efficient.
