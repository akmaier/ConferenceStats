Implementation Details

1.1

Student Generator and Discriminator Settings

The student generator contains 6 convolutional layers. Each layer adopts the
convolutional filter that has a 3 × 3 kernel with stride 1 and padding 1. The
input and output of each layer are of dimension 224 × 224. At the last layer,
a sigmoid function is applied to output the subject map with each pixel value
ranging from 0 to 1.
The discriminator has 12 convolutional layers. The kernel sizes are set to
3 × 3. It down samples an input with width 224 × height 224 to a binary output
for the real or fake classification.
1.2

Experiments Settings for I3D

Our I3D models are initialized from 2D CNNs pre-trained on ImageNet [4], and
we choose ResNet [2] as our backbone. Every input clip has 8 frames, which is
sampled from 64 consecutive frames with a stride of 8. The I3D input size is
8 × 3 × 224 × 224. The batch size is set to 128 and the momentum is set to 0.9.
We train the 3D models for 60 epochs with mini-batch SGD, The initial learning
rate is 0.01 and the learning rate will be divided by 30th at the 40th and 50th
epoch. Location jittering, horizontal flipping, corner cropping, and scale jittering
are used for data augmentation.
