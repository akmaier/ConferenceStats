Network Architectures

PalGAN contains Palette Generator, Palette Assignment Generator, and Color
Discriminator. We detail their topology and configuration below. For clarity,
we denote Conv(k, s, c) indicates a convolutional operation whose kernel size,
stride size, and output channel number of the used convolution are k, s, and c,
respectively. The dilation ratio and padding size of Conv(k, s, c) are both set
to 1. FC(cin ,cout ) denotes a fully-connected operation where cin and cout stands
for input channel and output one, respectively. ↑ and ⊗ denote a 2× bilinear
upsampling and concatenation (along with the channel dimension) operations,
respectively. ResBlock(k, s, c) denotes a residual block as used in [3,5].
Palette Generator : L → Conv1 (3,2,32) → LReLU → Conv2 (3,2,64) → LReLU
→ Conv3 (3,2,128) → LReLU → Conv4 (3,2,256) → LReLU → Conv(3,2,256) →
LReLU → Conv(3,2,256) → LReLU → FC(4096,256) → Sigmoid → ĥ.

Palette Assignment Generator : L ↓ ⊗M4 → Conv1 (3,2,512) → LReLU →
ResBlock(3,1,512) → ResBlock(3,1,512) →↑ [⊗M3 ] → ResBlock(3,1,256) →
ResBlock(3,1,256) (S) →↑ [⊗M2 ] → ResBlock(3,1,128) → ResBlock(3,1,128)
→↑ [⊗M1 ] → ResBlock(3,1,128) → ResBlock(3,1,64) → CA(S,L) →↑ → Conv
(3,1,2) → tanh → Î,
where Mi indicates the output from Convi in Palette Generator.
Color Discriminator : Ĉ⊕ Î or C⊕I → Conv(3,2,32) → LReLU → Conv(3,2,64)
→ LReLU → Conv(3,2,128) → LReLU → Conv(3,2,256) → LReLU → Conv(3,2,256)
→ LReLU → FC(128,256) → proj(h) → T or F,
where proj is the conditional projection (Eqn. 9) in the paper.
