Implementation Details

In this section, we provide additional implementation details of the proposed
SeedFormer.
Encoder. We use point transformer [8] (SA) and set abstraction [1] (P T ) layers
to extract features from an input point cloud. The point cloud (with 2,048 points)
is downsampled using FPS in each layer of set abstraction. Detailed network
architecture is as follows: SA(C = 128, N = 512) → P T (C = 128) → SA(C =
256, N = Np ) → P T (C = Cp ). The outputs are Np = 128 patch centers Pp as
well as the corresponding patch features Fp with Cp = 256 channels.
Seed Generator. The inputs to seed generator are the obtained patch centers Pp and correponding patch features Fp . The implementation of Upsample
Transformer (Eq. 1 in the main paper) is slightly different from that in an upsample layer. Since there are no skipped features, we use Fp , applied by linear
projections, for both keys and queries in the transformer. Also, the positional
encoding of each point is calculated without incorporating seed features. Then,
after we obtain seed features F, we concatenate them with a pooled feature
from Fp which is used for encoding global contexts, and apply shared MLPs to
produce the seed coordinates S.
Experimental settings. For PCN dataset (with 16,384 points in groundtruth), we set the upsampling rate as r1 = 1, r2 = 4, r3 = 8 where the first
upsample layer is used to refine the input coarse point cloud P0 . For ShapeNet34/55 (8,192 points), we set r1 = 1, r2 = 4, r3 = 4. Each input point cloud from
all datasets contains 2,048 points. For those point clouds with less than 2,048
points, we randomly duplicate input points; for those with more than 2,048
points, we pick a subset as input.
