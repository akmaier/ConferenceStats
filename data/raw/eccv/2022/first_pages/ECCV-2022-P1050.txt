Proof of Theorem 2

Proof. First we make some notations. Suppose we have a grid of size (q, q). For a
position (x, y) that 1 ≤ x, y ≤ q, denote U L(x, y) to be the generalized window
with size (q/2 + pn , q/2 + pn ) whose upper left corner lies on (x, y), and L(y) to
be the set of generalized windows with size (q/2 + pn , q/2 + pn ) whose left side
lies on y. For a generalized window M , denote L(M ), R(M ), U (M ), Lo(M ) to
be the position of left, right, upper and lower side respectively.
Considering two generalized windows M1 , M2 with size (pn , pn ) on the q × q
grid. Without loss of generality, we assume L(M1 ) ≤ L(M2 ). Also we assume
U (M1 ) ≤ U (M2 ), otherwise we can rotate the grid, and find the generalized
window on the rotated grid that corresponds to the one on origin grid. Now we
consider different cases.
1. If x2 − x1 ≤ q/2, y2 − y1 ≤ q/2, obviously U L(x1 , y1 ) satisfies.
2. If x2 − x1 ≤ q/2, y2 − y1 > q/2, we have ∀M ∈ L(y2 ), R(M ) ≥ y1 + pn .
So we only need to find x such that Lo(U L(x, y2 )) ≥ max{x1 + pn , x2 + pn }.
Actually x = x1 is enough, so choose the generalized window to be U L(x1 , y2 ).
3. If x2 − x1 > q/2, y2 − y1 ≤ q/2, similarly, we can choose U L(x2 , y1 ).
4. If x2 − x1 > q/2, y2 − y1 > q/2, choose U L(x2 , y2 ).
Hence such generalized window exists for all cases.
