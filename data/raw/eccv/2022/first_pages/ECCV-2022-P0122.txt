Appendix A : More Implementation Details

Branch Label Assignment To train our SPOT [8], the ground-truth needs
to be arranged into a specific format. Concretely, given a training video with
temporal intervals and action class labels (Fig. 1(a)), we assign all the snippets
(e.g., the orange and green squares of class branch in Fig. 1(a)) lying in each
action interval as (positive) action snippets with the shared action class. All
the snippets outside of any action interval are labeled as (negative) background
samples. For an action snippet in mask branch M , its segmentation mask label is
defined as the full binary mask of the associated action instance with the whole
video length (the columns with a sequence of blue squares in Fig. 1(a)). When
there are multiple action snippets involved in a specific action instance (e.g., 5/5
snippets covered by the first/second action instance from class i/j in Fig. 1(a),
each will be assigned with the global segmentation mask label corresponding to
that instance.
