Network Architecture

NeRF Architecture We adopt the same MLP architecture as the original NeRF [4].
We use 8 full-connected layers to obtain density σ with channel equals to 256.
The last layer uses a shifted softplus log(1 + exp(x − 1)) as the activation while
the rest layers use ReLU activation functions. The additional branch for RGB
color prediction contains a full-connected layer using a “widened” sigmoid activation (1 + 2ϵ)/(1 + exp(−x)) − ϵ and 128 channels. Similar to Mip-NeRF [1],
the ϵ is set to 0.001. Such design avoids failure modes when MLP emits negative
values everywhere and the vanishing gradient issue of sigmoid.
