Abstract

1. Introduction

Automatic colorization of line drawings has been widely
studied to reduce the labor cost of hand-drawn anime production. Deep learning approaches, including image/video
generation and feature-based correspondence, have improved accuracy but struggle with occlusions, pose variations, and viewpoint changes. To address these challenges,
we propose DACoN, a framework that leverages foundation
models to capture part-level semantics, even in line drawings. Our method fuses low-resolution semantic features
from foundation models with high-resolution spatial features from CNNs for fine-grained yet robust feature extraction. In contrast to previous methods that rely on the Multiplex Transformer and support only one or two reference
images, DACoN removes this constraint, allowing any number of references. Quantitative and qualitative evaluations
demonstrate the benefits of using multiple reference images,
achieving superior colorization performance. Our code and
model are available at https://github.com/kzmngt/DACoN.

In anime production, animators color line drawings as part
of the workflow. As shown in Figure 1, anime line drawings consist of keyframes, which capture critical moments
in motion, and inbetweens, which interpolate frames between these keyframes [34]. Keyframes are manually colorized using color design sheets, which provide a standardized reference for character colors, while inbetweens rely
on the colorized keyframes. These tasks are referred to as
keyframe colorization and consecutive frame colorization,
respectively [6].
The core manual process for anime colorization is often termed paint bucket colorization, which specifically
involves painters using a paint bucket tool and a designated color palette to fill completely line-enclosed segments. While various digital drawing tools have been developed to improve efficiency, color assignment still relies
heavily on manual work. Automatic colorization methods
